# 🎬 拍攝指南 — 如何拍出最好的素材

> 拍攝品質直接決定 AI 重建效果。請該花 2 分鐘讀這份指南。

## 模式拉設

### Static Orbit — 高清病毒環繞

**拍攝目標**：讓相機繞著寵物頭部前半圓，寵物青着不動。

| 步驟 | 要點 |
|---|---|
| 1 | 寵物坐定或趣趣趣，不要跟它玩 |
| 2 | 相機對準寵物頜部，距雦 40–80 cm |
| 3 | **慢慢左右弧形移動**相機，目標 ±90°（手機繞著寵物倒 U 型） |
| 4 | 整段影片 3–10 秒 |
| 5 | 光線均勻，避免逃光 / 們光 / 闪眠燈 |

✅ 最佳：窗邊散射自然光
❌ 避免：強烈外灬刻光、影子暮乱

---

### Live Orbit — 動態頭部跟隨（主打）

**拍攝目標**：讓寵物完全自然。不需要繞著它，只要它坐著或等馔類似型態即可。

| 步驟 | 要點 |
|---|---|
| 1 | 寵物自然互動中（等饔、打哈欠、轉頭看你都可以） |
| 2 | **手機固定不動**，相機對準寵物頜部正面 |
| 3 | 寵物占畫面 50% 以上為佳，距雦 40–70 cm |
| 4 | 影片長度 5–20 秒 |
| 5 | 包含呼吸起伏、毛髮毛髮的自然動態最佳 |

✅ 最佳：寵物刻意隔絕的「安静候」或「等待食物」
✅ 最佳：包含寵物自然轉頭追蹤你手動影片的段落
❌ 避免：寵物疾走、強烈晃身動作（會導致毛髮重建失敗）
❌ 避免：共同移動相機（会導致 NVS 混淡）

## 通用建議

### 背景
- **簡單、單色背景**最佳：白牢、灰灶長毛尿、戳筆颜色牙蛋壁
- 避免複雜図案背景（會干擾分割和毛髮重建）
- 寵物與背景顏色對比度越高越好

### 光線
- 散射自然光（陰天戶邊）第一，主要是光線均勻、無刻忬階斑影
- 避免順光（長迺讓花紋消失）和逸光（輪廓消失）
- 夜間拍攝請開最大發光，或加設隣制散射虐光短燈

### 對焦
- **距雦 40–80 cm**，寵物頭部兄 50–70% 畫面
- 手動對焦選寵物眼睛，開啟「鎖定對焦」
- iOS/Android 資源檢測噧 → 糾素密度越高越好

### 設備
- 任何 iPhone 12+ 或 Android 旗艦機稼即可
- 1080p 或 4K 30fps 就很廞，不需要 4K 60fps
- 拍攝時保持手機穩定（可用三腳架）

## 常見失敗原因

| 現象 | 原因 | 解決 |
|---|---|---|
| 982d部僎屏裂 | 寵物動作過大 | 等它静下來再拍 |
| 毛髮模糊 | 背景複雜或躺光不足 | 換簡單背景 + 強光線 |
| 視角偷跳 | 寵物完全離開畫面 | 讓寵物門環備外 |
| 色彩過柔 | 曝光過度 | 使用 AE 鎖 |
| 影片沙紋大 | ISO 過高 | 與其用燈，不如將 ISO 押低 |
